# 포켓 몬스터즈 Y — 옐로 어드벤처

포켓몬스터 옐로에서 영감을 받은 게임보이 스타일 웹 RPG. 의존성 없는 정적 파일 3개로 동작합니다.

| 파일 | 역할 |
|---|---|
| [index.html](index.html) | 셸 UI + 터치 컨트롤 |
| [data.js](data.js) | 픽셀 스프라이트 · 도감 · 맵 · 트레이너 · 칩튠 악보 |
| [game.js](game.js) | 게임 엔진 (월드/배틀/UI/오디오/세이브) |

## 실행

브라우저에서 `index.html`을 바로 열거나:

```sh
python3 -m http.server 8642
# http://localhost:8642 접속
```

데이터 정합성 검사(개발용): `node validate.js`

## 조작

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| Z / Enter / Space | 결정 · 말 걸기 · 대사 넘기기 |
| X / Shift | 취소 · 필드 메뉴 |
| M | 소리 켜기/끄기 |

모바일에서는 화면 아래 가상 D패드 + A/B 버튼이 자동 표시됩니다.

## 게임 내용

- **타이틀 → 인트로 → 모험**: 박사에게 파트너 「볼티」를 받으며 시작. 옐로 버전처럼 선두 몬스터가 필드에서 뒤를 따라다닙니다.
- **3개 맵**: 옐로 마을(회복·상점·연구소 보관함) → 1번 도로(풀숲·트레이너) → 몬스터 스타디움(관장전)
- **트레이너 배틀**: 시야에 들어가면 「!」 와 함께 승부 발생. 수집가·낚시꾼·라이벌 2연전·관장까지 총 5명. 승리 시 상금.
- **턴제 배틀**: 타입 상성 7종(전기/풀/불꽃/물/바위/비행/노말), 자속 보정, 급소, 스피드 선공, 교체, HP/경험치 바 애니메이션, 전투 전환 연출.
- **포획·성장·진화**: 몬스터볼 포획(HP가 낮을수록 확률↑), 레벨업 기술 습득, 12종 도감, 6종 → 6종 진화(연출 포함). 파티 6마리 초과분은 연구소 보관함으로.
- **경제**: 상금으로 상점에서 몬스터볼·물약·고급 물약 구매. 전멸 시 소지금 절반 분실 + 마을 부활.
- **엔딩**: 관장을 꺾으면 챔피언 등극 + 스태프롤. 클리어 후에도 모험 계속.
- **칩튠 사운드**: Web Audio 시퀀서 BGM 4곡(타이틀/필드/배틀/승리) + 효과음 10종.
- **세이브**: localStorage 자동 저장 + 필드 메뉴 「리포트」. 타이틀에서 이어하기.
